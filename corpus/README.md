# Corpus

Kubernetes concept documentation, from
[kubernetes/website](https://github.com/kubernetes/website).

© The Kubernetes Authors, licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Included here
unmodified apart from the publishing system's front matter and shortcodes,
which the ingester strips.

Chosen because it is public, genuinely technical, and messy in the way real
documentation is — YAML front matter, Hugo shortcodes, deeply nested headings
and long tables. Clean markdown would not have exercised the ingester.

Swap this directory for your own documents and re-run `./rag ingest`.
